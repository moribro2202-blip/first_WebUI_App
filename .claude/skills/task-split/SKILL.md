# タスク分割・ToDo管理

要件定義（docs/requirements/functional.md）を参照して、機能ごとにタスクを分割し、ToDoファイルを作成します。

## When to Use This Skill

- 新しい機能の実装を始める時
- 要件定義からタスクを洗い出したい時
- 「タスク分割して」と依頼された時

## ファイル構造

```
docs/
├── requirements/
│   └── functional.md        # 要件定義（参照元）
└── tasks/
    ├── 000_overview.md      # 全体概要・依存関係図
    ├── 001_認証機能.md
    ├── 002_ホーム画面.md
    ├── 003_検索機能.md
    └── ...
```

## タスクファイル形式

### 000_overview.md（全体概要）

```markdown
# タスク概要

## 機能一覧

| No | 機能名 | ステータス | 依存 |
|----|--------|-----------|------|
| 001 | 認証機能 | 🔴 未着手 | - |
| 002 | ホーム画面 | 🔴 未着手 | 001 |
| 003 | 検索機能 | 🔴 未着手 | 001 |

## ステータス凡例

- 🔴 未着手
- 🟡 進行中
- 🟢 完了

## 依存関係図

```
001_認証機能
    ├── 002_ホーム画面
    ├── 003_検索機能
    └── 004_プロフィール
```
```

### 個別タスクファイル（例: 001_認証機能.md）

```markdown

### UI実装
```

## AI Assistant Instructions

### タスク分割時の手順

1. `docs/requirements/functional.md` を読み込む
2. 機能ごとにタスクファイルを作成
3. `000_overview.md` に全体像と依存関係を記述
4. 各タスクは小さく分割（1-2時間で完了できる粒度）

### ファイル命名規則

- 3桁の連番 + アンダースコア + 機能名
- 例: `001_認証機能.md`, `002_ホーム画面.md`

### ToDo更新ルール

- 作業開始時: ステータスを 🟡 進行中 に変更
- 完了時: チェックボックスを `[x]` に、完了履歴に日付を追記
- 全ToDo完了時: ステータスを 🟢 完了 に変更
- `000_overview.md` のステータスも同時に更新

### タスク分割の粒度

```
❌ 悪い例: 「認証機能を実装」（大きすぎる）
✅ 良い例:
  - Firebase Authentication 設定
  - AuthContext 作成
  - サインイン画面 UI
  - サインインロジック実装
  - エラーハンドリング追加
```

### 依存関係の記述

- 先に完了すべきタスクを「依存先」に記載
- 完了後に着手可能になるタスクを「依存元」に記載
