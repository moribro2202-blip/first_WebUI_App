# Git Commit Message Generator

変更内容に基づいて適切なコミットメッセージを生成します。

## When to Use This Skill

- コミットメッセージを作成する時
- 「コミットして」と依頼された時
- 変更内容をコミットする時

## コミットメッセージ形式

```
<type>: <subject>

<body>

🤖 Generated with Claude Code
```

## プレフィックス一覧

| プレフィックス | 用途 | 例 |
|---------------|------|-----|
| `feat` | 新機能追加 | feat: ログイン機能を追加 |
| `fix` | バグ修正 | fix: 認証エラーを修正 |
| `docs` | ドキュメント | docs: READMEを更新 |
| `style` | フォーマット | style: インデントを修正 |
| `refactor` | リファクタリング | refactor: 認証ロジックを整理 |
| `test` | テスト | test: ログインテストを追加 |
| `chore` | ビルド・設定 | chore: 依存関係を更新 |

## 書き方ルール

### Subject（タイトル）

- 50文字以内
- 句点（。）は付けない
- 「〜を追加」「〜を修正」「〜を更新」の形式

### Body（本文）

- 変更の理由や詳細を記述
- 箇条書きで複数の変更を列挙可能
- 省略可能（小さな変更の場合）

## 例

### 新機能追加

```
feat: ユーザープロフィール編集機能を追加

- プロフィール画像のアップロード機能
- 表示名の変更機能
- Firebase Storageとの連携
```

### バグ修正

```
fix: ログイン時のクラッシュを修正

認証トークンがnullの場合の処理が
抜けていたため追加
```

### 複数ファイルの変更

```
refactor: 認証関連のコードを整理

- AuthContextをhooksに分離
- 型定義をtypes/auth.tsに移動
- 不要なコメントを削除
```

### ドキュメント更新

```
docs: セットアップ手順を更新
```

### テスト追加

```
test: LoginFormのバリデーションテストを追加

- 空入力のエラー表示
- 無効なメールアドレスの検証
- 正常系のテスト
```

## AI Assistant Instructions

コミットメッセージ生成時:

1. `git diff --staged` で変更内容を確認
2. 変更の種類に応じたプレフィックスを選択
3. 変更内容を簡潔に要約してSubjectを作成
4. 必要に応じてBodyで詳細を説明
5. 日本語で記述

### 禁止事項

- 英語でのメッセージ作成（指示がない限り）
- 曖昧な表現（「修正」「更新」だけ）
- 50文字を超えるSubject
