# 競馬AI予想 M7モデル シミュレーション報告書

## 1. M7モデルに至った経緯

JRDBデータを用いた三連複予測モデルを25バージョンにわたって改良。

| 段階 | 内容 | 回収率 | 問題 |
|------|------|--------|------|
| v1-v7 | 自作特徴量（騎手勝率+馬成績）、2026年のみ | 110% | 2026年だけの偶然 |
| v16 | 年別検証（2021-2026通算） | 87% | 6年通算で大赤字 |
| v21 | パラメータ総当たり2,268通り | 91.8% | 全レース賭けでは勝てない |
| v22 | 選択的ベッティング（堅いレースだけ賭ける） | 110% | 自作モデルの限界 |
| v23 | JRDB IDM指数を導入 | 113% | 市場オッズフィルタに依存 |
| v24 | 予想オッズフィルタに切り替え | 131% | Harville補正が必要 |
| **v25** | **Stern補正+外部監査対応** | **131.6%** | **最終版** |

転機はv23でJRDBのIDM（スピード指数）を導入したこと。市場が完全に織り込んでいない情報源を得たことでモデルの精度が劇的に向上した。

## 2. M7モデルの概要

| 項目 | 値 |
|------|-----|
| モデル名 | M7 Full Combined |
| 賭け方 | 三連複◎○▲ 1点（1万円固定） |
| フィルタ | 予想オッズ(PredBlend) ≤ 8倍 |
| Harville補正 | Stern λ1=0.9, λ2=0.8 |
| ブレンド | モデル50% + 市場50%（α=0.50） |
| 通算回収率 | **131.6%**（6年間5,350R） |
| 外部監査 | Claude Fable5評価済み、全6指摘対応完了 |

## 3. スコアリング（7つの特徴量）

| 特徴量 | 説明 | 出典 |
|--------|------|------|
| **IDM** | JRDBのスピード指数（ベーススコア） | TYB（当日朝） |
| **騎手指数** | JRDBの騎手評価値 | TYB（当日朝） |
| **馬場適性** | 当日の馬場状態（良/稍重/重/不良）での過去成績 | BAC + SED |
| **脚質補正** | 逃げ+1.0、先行+0.5、追込-0.3 | KYI |
| **体重安定性** | ±4kg以内=+0.5、±10kg超=-1.5 | SED |
| **距離適性** | 同距離±200mでの過去着順 | SED |
| **馬場適性** | 同馬場（芝/ダート）での過去着順 | SED |

## 4. フィルタの仕組み

1. 各馬のスコアをsoftmaxで確率に変換
2. 前日単勝オッズからも市場確率を計算
3. 両者をlog-linearブレンド（α=0.50）
4. Stern補正付きHarvilleモデルで三連複的中確率を推定
5. 予想オッズ = (1/的中確率) × 0.75
6. **予想オッズ ≤ 8倍のレースだけ賭ける**（年間約890R、全体の約30%）

## 10. 外部監査（Claude Fable5）

| 指摘 | 結果 | 影響 |
|------|------|------|
| IDMデータリーク | **リークなし確認**（勝率22%、相関-0.23） | 0pt |
| 払戻計算の楽観性 | 確定/前日比=0.994 | **-0.7pt** |
| 手決め重みバイアス | LOOで検証済み。モデル凍結予定 | 検証済 |
| OT異常値 | 500倍上限フィルタ追加 | 対応済 |
| Harville λ補正 | Stern(0.9,0.8)で改善 | **+9pt** |
| キャリブレーション | 0.72x → 0.92x（予測精度向上） | 信頼性向上 |

監査後の結論：**回収率131.6%は本物のエッジ。**
