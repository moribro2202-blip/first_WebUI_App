## 1. プロジェクト概要

個人開発者が競馬の予想AIを構築。JRDBという専門データベースのデータを用い、25回のモデル改良と120万通りのパラメータ探索を経て、6年間の実データで回収率122.7%（=賭けた金額の122.7%が戻ってくる）を達成した。2026年9月5日の実運用初日は19レースに賭けて3的中、回収率122.1%。

## 3. M7モデルの仕組み

### スコアリング（馬の強さを数値化）

7つの要素を組み合わせて各馬にスコアをつける：

| 要素 | 説明 | 重要度 |
|------|------|--------|
| IDM | JRDBが算出するスピード指数。過去のタイムを馬場やペースで補正した実力値 | 最高 |
| 騎手指数 | 騎手の当日評価。馬との相性も考慮 | 高 |
| 馬場適性 | 良/稍重/重/不良での過去成績 | 中 |
| 脚質 | 逃げ・先行・差し・追込の走り方 | 中 |
| 体重安定性 | 急激な体重変化はマイナス | 中 |
| 距離適性 | 同じ距離±200mでの過去成績 | 中 |
| 芝/ダート適性 | 同じ馬場タイプでの過去成績 | 中 |

### 確率計算

1. 各馬のスコアを確率に変換（softmax）
2. 市場のオッズからも確率を計算
3. モデル50%＋市場50%でブレンド
4. 上位3頭の三連複的中確率をHarville＋Stern補正で計算
5. 予想オッズ（PredBlend）が8倍以下のレースだけ賭ける

### なぜ「予想オッズ8倍以下」で絞るのか

モデルが「この3頭が上位3着に入る確率が高い」と強く確信しているレースだけに賭ける。確信が低いレース（予想オッズが高い）は見送る。これにより年間約900レース（全体の30%）に絞り込む。

## 6. 外部監査（Claude Fable5）

独立したAIモデルに技術仕様書を提出し、6つの重大指摘を受けた。全て対応済み。

| 指摘 | 結果 | 影響 |
|------|------|------|
| IDMデータリーク | リークなし確認（勝率22%、相関-0.23） | 0pt |
| 払戻計算の楽観性 | 確定/前日比率=0.994 | -0.7pt |
| 手決め重みバイアス | LOOで検証済み | 検証済 |
| OT異常値 | 500倍上限追加 | 対応済 |
| Harville λ補正 | Stern(0.9,0.8)で改善 | +9pt |
| キャリブレーション | 0.72x→0.92xに改善 | 信頼性向上 |

### オッズ帯分析への追加監査

「12-15倍帯の回収率145.9%は本物か？」を再度Fable5に検証依頼。

結論：
- 12-15倍帯の145.9%は**多重比較のノイズ**（12区間の最大値を拾っただけ、補正後p=0.53）
- 10-30倍帯の130.7%も「有意に近いが未確定」（z=1.75）
- **オッズ帯フィルタではなくEVフィルタに置き換えるべき**との指摘

### EV閾値フィルタの検証

Fable指摘に基づきEV = モデル予測確率 × 市場オッズ ≥ θ でスキャン：

| θ | R数 | 回収率 | 年間PnL |
|---|-----|--------|---------|
| なし(現行) | 5,352 | 122.7% | +202万 |
| ≥1.0 | 4,491 | 123.8% | +178万 |
| ≥1.2 | 3,696 | 123.6% | +145万 |
| ≥1.5 | 2,310 | 127.9% | +108万 |

**結論：追加フィルタは回収率を上げるがR数が減り、年間利益は現行が最大。現行モデルを維持。**

## 11. なぜ勝てるのか

1. **JRDBのIDM指数が市場に完全に織り込まれていない** — 一般の馬券購入者はIDMを使っていない
2. **PredBlendフィルタで確信度の高いレースだけ選別** — 全レースに賭けるのではなく、モデルが自信を持つ30%だけ
3. **下級条件（新馬・未勝利）で特にエッジが大きい** — 市場の効率性が低い
4. **Stern補正でHarville確率の精度を向上** — 外部監査で指摘され改善

## 12. リスクと注意点

1. **バックテスト上の結果** — 将来の利益を保証しない
2. **最大連敗49回** — 精神的に厳しい期間がある
3. **6月・12月が弱い** — 季節性あり
4. **JRDBデータへの依存** — サービス変更で影響を受ける
5. **2021-2022年は成績が低い** — コロナ影響の可能性
6. **エッジの寿命は不明** — 市場がIDMを織り込み始めたら消える
7. **12-15倍帯の高回収率は多重比較のノイズ** — 特定オッズ帯への過信は禁物

## 13. 監視と運用ルール

- **モデル凍結** — パラメータ変更禁止
- **四半期ごとにEV通過点の実現回収率を監視**
- **低下トレンドが3四半期続いたらエッジ減衰の疑い**
- **ペーパートレードで検証後に実運用へ移行**
- **損切りライン：累積回収率90%以下で運用見直し**
