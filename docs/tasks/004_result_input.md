# Task 4: 結果入力・収支管理

## 概要

レース結果（着順・配当）と購入馬券を入力し、収支を自動計算する。

## タスク

- [ ] 結果入力フォーム（予想履歴から選択 → 結果入力）
  - 1着・2着・3着の馬番入力
  - 馬券種別ごとの配当金入力
- [ ] 購入馬券記録フォーム
  - 馬券種別選択
  - 買い目（組み合わせ）入力
  - 購入金額入力
  - 複数馬券の追加・削除
- [ ] 収支自動計算
  - 的中判定（買い目 vs 着順）
  - 払戻金の計算
  - 収支（利益/損失）の表示
- [ ] 結果データを Firestore（or localStorage）に保存

## 作成ファイル

```
src/
├── components/features/result/
│   ├── result-input-form.tsx    # 結果入力フォーム
│   ├── bet-record-form.tsx      # 購入馬券記録
│   └── profit-summary.tsx       # 収支サマリー
└── lib/
    └── calc-profit.ts           # 的中判定・収支計算ロジック
```

## 完了条件

- 結果入力 → 的中判定 → 収支計算が正しく動作する
- データが永続化される
