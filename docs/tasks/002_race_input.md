# Task 2: レース情報入力画面

## 概要

`/predict` 画面でレース基本情報と出馬表を手動入力するフォームを作成する。

## タスク

- [ ] レース基本情報フォーム
  - 開催場（セレクト: 東京/中山/阪神/京都/中京/小倉/札幌/函館/福島/新潟）
  - レース番号（1-12）
  - レース名（テキスト）
  - 日付
  - 発走時刻
  - 距離（数値）
  - 馬場（芝/ダート）
  - 馬場状態（良/稍重/重/不良）
  - 中央/地方 切り替え
- [ ] 出馬表入力フォーム
  - 頭数指定 → 入力行を動的生成
  - 各行: 馬番/馬名/騎手/斤量/オッズ/人気/年齢/調教師
  - 行の追加・削除
- [ ] Zod バリデーション
- [ ] 入力データを RaceInfo 型に変換

## 作成ファイル

```
src/
├── app/predict/page.tsx
├── components/features/predict/
│   ├── race-form.tsx          # レース基本情報フォーム
│   └── entries-form.tsx       # 出馬表入力フォーム
└── lib/
    └── validations/race.ts    # Zodスキーマ
```

## 完了条件

- レース情報を入力して RaceInfo オブジェクトが生成できる
- バリデーションエラーが適切に表示される
