# Task 3: AI予想生成・表示

## 概要

入力されたレース情報を既存の `/api/predict` に送信し、AI予想結果を表示する。

## タスク

- [ ] 予想生成ボタン・ローディング状態
- [ ] 予想結果表示コンポーネント
  - AI偏差値ランキング表（馬番・馬名・AI偏差値・推奨度・理由）
  - 推奨度アイコン表示（◎○▲△☆）
  - 偏差値のカラーバー表示
- [ ] 推奨買い目表示コンポーネント
  - 馬券種別タブ（単勝/複勝/馬連/馬単/ワイド/三連複/三連単）
  - 各買い目と信頼度（星表示）
- [ ] レース全体の分析コメント表示
- [ ] 予想結果を Firestore（or localStorage）に保存
- [ ] エラーハンドリング（API キー未設定、通信エラー等）

## 作成ファイル

```
src/components/features/predict/
├── prediction-result.tsx       # 予想結果全体
├── horse-ranking-table.tsx     # AI偏差値ランキング表
├── recommended-bets.tsx        # 推奨買い目表示
└── analysis-comment.tsx        # 分析コメント
```

## 完了条件

- 入力 → 予想生成 → 結果表示の一連フローが動作する
- 全馬券種の推奨買い目が表示される
- 予想データが永続化される
