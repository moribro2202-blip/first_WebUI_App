## 0. 定義

オッズの歪みとは、**市場の暗黙確率 π と真の確率 p の系統的なズレ**のこと。

- 個々のレースのズレは運と区別がつかない
- 大量のレースを集計して初めて測定できる
- 測定方法は大きく4つ（下記 1〜4）、最終的には一つのエッジ量に集約する（5）

### 前提：市場確率の抽出

```
π_i = (1/O_i) / Σ_j (1/O_j)
```

分母で正規化して控除率を除去する。

---

## 1. オッズ帯別キャリブレーション（本命-穴バイアスの測定）

最も基本の歪み。favorite-longshot bias（人気薄は過大に買われ、本命は過小に買われる傾向）を集計で測る。

### 手順

```
1. 全馬を市場確率 π でビン分割（対数等間隔で10〜20帯）
2. 各ビンで計算：
   実測勝率      p_hat = 勝利数 / 出走数
   平均市場確率  π_bar = Σπ / 出走数
   歪み率        d = p_hat / π_bar
3. d を π_bar に対してプロット
```

### 読み方

| 歪み率 | 意味 |
|---|---|
| d > 1 | 市場が過小評価している帯（買い場候補） |
| d < 1 | 市場が過大評価している帯（避ける） |

- 中央競馬では歴史的に、超人気薄（単勝50倍以上）で d ≈ 0.6〜0.7 まで落ち、1〜3倍台では 1 に近いかわずかに超える形が知られる

### 注意

- 各ビンの実測勝率には二項誤差 sqrt(p_hat(1-p_hat)/n) が付く。**誤差棒なしで判断しない**
- 1ビンあたり最低でも数千頭が必要
- **全ての出発点。まず自分のデータでこの曲線を引く**

---

## 2. キャリブレーション関数のフィット（連続的な補正）

ビン集計は「見る」ためのもの。「使う」ためには連続関数でフィットする。

### べき乗補正（標準形）

```
p_i = π_i^β / Σ_j π_j^β
```

| β | 意味 |
|---|---|
| β = 1 | 市場は無歪み |
| β > 1 | 本命-穴バイアスあり（人気馬をさらに強く、人気薄をさらに弱く見るのが正しい） |

- β は過去データの対数尤度最大化で1パラメータ推定

### ロジット回帰（同等の代替）

```
logit(p_i) = a + b * logit(π_i)
```

### 重要：ベースラインの設定

- こうして得た p(π) が「市場オッズだけから作れる最良の確率」
- **モデル評価のベースラインは生の π ではなく β補正済みの p(π) にする**
- 生の π をベースラインにするとモデルの見かけの成績が水増しされる

## 3. クロスプール比較（券種間の歪み）

単勝プールと馬連プールは別の資金で価格が付くため、両者の整合性のズレが歪みとして測れる。

### 手順

```
1. 単勝オッズ → π_i 抽出 → β補正 → Harville(λ補正済)で馬連確率 q_ij を合成
2. 馬連オッズ全点 → 正規化して市場確率 π_ij を抽出
3. 各点の歪み: r_ij = q_ij / π_ij
```

- r > 1：単勝市場の評価に比べて馬連が安い → 買い目候補

### 注意点

1. **歪みの切り分けが必要**
   - 1には Harville近似の誤差が入る
   - r のズレが「市場の歪み」か「自分の近似の歪み」かを切り分ける
   - 方法：r_ij を実際の的中結果に回帰する
     - r が高い組が統計的に多く的中している → 市場の歪み（使える）
     - そうでない → 自分の近似誤差（使えない）
2. **複勝・ワイドは判定を緩める**
   - 払戻レンジ問題により π の抽出自体が不正確になるため、判定閾値を緩めに取る

## 4. オッズの時間変動（スマートマネーの検出）

締切前のオッズ推移そのものが情報を持つ。OZファイルの時系列取得が前提。

### 計算

```
オッズ変化率: m_i = ln(π_i^final / π_i^early)
```

- m > 0（締切にかけて買われた馬）は、朝のオッズが示す確率より実際の勝率が高い現象が複数の市場で報告されている
- 解釈：終盤に入る資金ほど情報を持った投票者のものである割合が高い

### 検証方法

- m でビン分割して実測勝率を確認する、または
- ロジットモデルに π^final と m を両方入れ、m の係数が有意に正かを見る
- 有意なら m はそのまま特徴量になる

### 罠：情報の時点を揃える

- 「最終オッズ + スマートマネー」で買う場合、その判断時点で最終オッズは未確定
- 実運用は「**締切5分前のオッズ + そこまでの変化率**」で判断する
- バックテストも同じ時点のデータで揃えること

---

## 5. まとめ：歪みを収益に変換する

最終的なエッジは一つの量に集約される。

```
edge_i = ln p_i - ln π_i^corrected
```

- p_i：自分のモデル確率（市場ブレンド後）
- π^corrected：β補正済みの市場確率

### 賭ける価値のある歪みの条件（両方必要）

1. edge > 0 であること
2. 過去データで「edgeの大きさと超過リターンが**単調に対応**している」ことを確認済みであること

- edgeが正でもリターンと対応していなければ、それはモデルの過信を測っているだけ
