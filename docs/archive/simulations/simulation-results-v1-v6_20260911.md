# シミュレーション結果

## 現行モデル: LightGBM + 1分前オッズ + τラグフィット

### モデル設計

| 項目 | 設定 |
|------|------|
| モデル | LightGBMオフセット学習（残差rを取得） |
| 市場確率 | 締切1分前単勝オッズ（β=1.015補正） |
| 強さ関数 | s_i = b * ln(π_i) + τ * r_i |
| τ推定 | 前年データでフィット → 翌年に適用（ラグ版） |
| 特徴量 | IDM, 騎手, 馬履歴, CYB, OZ乖離, 5→1分オッズ変動 等（24個） |
| LightGBM | lr=0.01, leaves=7, min_data=2000, L2=10.0, rounds=300 |
| 券種 | 単勝（EV判定）— 連系券種は不採用（v3で検証済み） |
| 払戻 | JRA-VAN確定オッズ |
| スクリプト | `scripts/phase4_tau_lagged.py` |

### ウォークフォワード構造

```
学習: 2015〜(test-2)年 → LightGBM学習
検証: (test-1)年 → b, τ フィット
テスト: test年 → Δ_τ・EV・回収率を測定
```

## v2: τ最適化スイープ（2026-09-11実施）

### 変更点
- τ推定窓サイズ（1年 vs 2年 vs 3年）比較
- b固定 vs b自由の比較
- LightGBMハイパーパラメータスイープ
- EV閾値 vs 年間利益の最適化

### Experiment 1: τ推定窓サイズ

| 窓サイズ | EV>=1.0 n | 回収率 |
|---------|-----------|--------|
| 1年（現行） | 47,789 | 103.5% |
| 2年 | 47,219 | 103.3% |
| 3年 | 47,195 | 102.5% |

→ **1年が最良**。窓を広げると古いτの影響でやや悪化。

### Experiment 2: b固定 vs b自由

| 設定 | Δ | EV>=1.0 n | 回収率 |
|------|------|-----------|--------|
| b=free（現行） | +0.00374 | 47,789 | 103.5% |
| b=0.85 | +0.00385 | 55,304 | 98.1% |
| **b=0.90** | **+0.00286** | **43,292** | **104.4%** |
| **b=0.95** | **-0.00096** | **37,576** | **107.0%** |
| b=1.00 | -0.00742 | 35,502 | 102.9% |

→ **b=0.95固定で回収率107.0%が最高**。bを固定すると安定性が向上。

### Experiment 3: LightGBMパラメータスイープ

| config | Δ | EV>=1.0 n | 回収率 | EV>=1.05 回収率 |
|--------|------|-----------|--------|----------------|
| baseline (leaves=7, lr=0.01, L2=10) | +0.00374 | 47,789 | 103.5% | 106.7% |
| leaves=15 | -0.00706 | 59,827 | 99.6% | 102.4% |
| leaves=31 | -0.03948 | 70,046 | 97.5% | 99.6% |
| lr=0.005 | +0.00448 | 46,500 | 104.2% | 107.0% |
| lr=0.02 | +0.00297 | 50,151 | 103.3% | 106.9% |
| L2=1 | +0.00362 | 48,150 | 103.0% | 106.6% |
| **L2=50** | **+0.00433** | **46,753** | **106.1%** | **108.5%** |
| rounds=500 | +0.00218 | 53,171 | 101.9% | 105.7% |

→ **L2=50（正則化強め）が最良**。leaves増やすと過学習で悪化。lr=0.005も微改善。

### Experiment 4: EV閾値 vs 年間利益

| EV>= | n | 回収率 | 年間PnL | 年間投資 |
|------|-------|--------|---------|---------|
| 0.95 | 61,453 | 99.2% | -53万 | 6,828万 |
| 1.00 | 47,789 | 103.5% | +187万 | 5,310万 |
| 1.02 | 43,418 | 104.9% | +236万 | 4,824万 |
| 1.05 | 37,827 | 106.7% | +283万 | 4,203万 |
| 1.08 | 33,100 | 109.5% | +350万 | 3,678万 |
| **1.10** | **30,435** | **110.7%** | **+362万** | **3,382万** |
| 1.15 | 24,906 | 111.5% | +319万 | 2,767万 |
| 1.20 | 20,473 | 114.0% | +318万 | 2,275万 |
| 1.30 | 13,811 | 119.0% | +292万 | 1,535万 |

→ **EV>=1.10で年間PnL+362万が最大**。回収率を追うなら1.20以上、利益最大化なら1.10。

### v1→v2の比較
- b=0.95固定でベースライン対比+3.5pt（103.5%→107.0%）
- L2=50で+2.6pt（103.5%→106.1%）
- EV閾値1.10で年間PnL最大+362万
- これらの組合せが実運用の最有力候補

## v3: 券種別シミュレーション — HJC確定オッズ払戻（2026-09-11実施）

### 変更点
- τ補正済み確率 → Harville-Stern（λ1=0.9, λ2=0.8）→ 全券種のコンボ確率計算
- 券種: 単勝/馬連/ワイド/三連複
- **払戻: HJC確定オッズのみ（フォールバック禁止）**
- θ（EV閾値）: 1.00〜1.20でスイープ
- EV判定にはconfirmed_odds（事前オッズ）を使用

### 券種別サマリー（θ=1.10）

| 券種 | n | 的中 | 回収率 | +年 | 払戻欠 |
|------|-------|------|--------|-----|--------|
| **単勝** | **17,102** | **958** | **119.3%** | **9/9** | **0** |
| ワイド | 188,158 | 6,946 | 77.9% | 0/8 | 587 |
| 馬連 | 239,560 | 3,252 | 72.7% | 0/8 | 215 |
| 三連複 | 1,035,585 | 4,175 | 63.0% | 0/8 | 285 |

→ **単勝のみが利益を出せる。連系券種は全滅。**

### 連系券種が不採用の理由
- Harville-Sternのコンボ確率精度が単勝ほど高くない（ワイド77.9%、馬連72.7%）
- EV>1.0の判定精度が足りず、大量のハズレを拾ってしまう（ワイド: 1レースあたり多数の偽陽性）
- 払戻欠（HJCデータ未収録）は的中全体の8%程度で、回収率への影響は軽微

## v6: リーク検証 — 1分前 vs 確定 vs HJC（2026-09-11実施）

### 変更点
- 払戻計算を4つのオッズソースで比較し、リークの有無を検証

### 結果（EV>=1.0）

| 払戻基準 | 回収率 | 意味 |
|---------|--------|------|
| A: 1分前オッズ | 109.8% | 参考値（実際には使えない） |
| **B: 確定オッズ(ts0)** | **108.9%** | 現行コード |
| **C: HJC（公式）** | **108.9%** | 正しい値 |
| D: SED | 108.9% | 一致 |

- B-A差 = -0.9pt（確定の方がやや低い）→ **リークなし、むしろ控えめ**
- 的中馬の確定/1分前比率 = 0.986（モデルが選んだ馬は確定時にオッズが下がる傾向）
- B/C/Dが全て一致 → HJC確定オッズでの計算は正確
