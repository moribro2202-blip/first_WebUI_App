# 非機能要件

## パフォーマンス

- ページ初期表示: LCP 2.5秒以内
- インタラクション応答: INP 200ms以内
- レイアウトシフト: CLS 0.1以下
- API応答: 2秒以内

## セキュリティ

- Firebase Authentication による認証
- Firestore セキュリティルールによるデータアクセス制御
- HTTPS 通信必須
- XSS / CSRF 対策

## 対応ブラウザ

- Chrome (最新2バージョン)
- Firefox (最新2バージョン)
- Safari (最新2バージョン)
- Edge (最新2バージョン)

## アクセシビリティ

- セマンティックHTML
- キーボードナビゲーション対応
- 適切なコントラスト比（WCAG 2.1 AA）
- スクリーンリーダー対応

## レスポンシブデザイン

- モバイル（320px〜）
- タブレット（768px〜）
- デスクトップ（1024px〜）

## SEO

- 適切なメタデータ設定
- OGP対応
- Server-Side Rendering / Static Generation 活用
