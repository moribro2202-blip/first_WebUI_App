# 非機能要件

## パフォーマンス

- 画面遷移: 300ms以内
- API応答: 2秒以内
- リスト描画: 60fps維持

## セキュリティ

- Firebase Authentication による認証
- Firestore セキュリティルールによるデータアクセス制御
- セキュアストレージによる機密情報保存

## 対応プラットフォーム

- iOS 15.0+
- Android API 24+ (Android 7.0+)

## アクセシビリティ

- VoiceOver/TalkBack 対応
- 適切なコントラスト比
- タップターゲット 44x44pt 以上

## オフライン対応

- Firestore オフライン永続化
- オフライン時のエラーハンドリング

## 多言語対応

- [ ] 日本語
- [ ] 英語（将来対応）
