# 機能要件

## ダッシュボード（ホーム画面）

- [x] 直近の成績サマリー（的中率・回収率）
- [x] 馬券種別の回収率表示
- [x] 最近の予想履歴（直近5件）

## レース予想機能

- [x] レース基本情報の手動入力（開催場・レース番号・レース名・距離・馬場・馬場状態）
- [x] 出馬表の手動入力（馬番・馬名・騎手・斤量・オッズ・人気・年齢・調教師）
- [x] Claude API による予想生成
- [x] AI偏差値の算出・表示
- [x] 推奨度表示（◎○▲△☆）
- [x] 予想根拠の表示
- [x] 全馬券種の推奨買い目表示（単勝/複勝/馬連/馬単/ワイド/三連複/三連単）
- [x] 買い目ごとの信頼度表示

## 結果入力機能

- [x] レース結果の手動入力（着順）
- [x] 配当金の入力
- [x] 購入馬券・金額の記録
- [x] 収支の自動計算

## 成績分析機能

- [x] 馬券種別の的中率・回収率集計
- [ ] 期間別の成績表示
- [x] 予想履歴一覧

## 設定機能

- [x] ダークモード切り替え
- [x] Claude API キー設定（環境変数 or UI入力）

## JRDB連携機能（Phase 2）

- [x] SQLiteデータベース構築（レース・出走馬・成績・馬マスタ）
- [x] JRDBファイルパーサー（BAC/KYI/SED/UKC固定長テキスト対応）
- [x] データインポート機能（設定画面から実行）
- [x] レースデータAPIエンドポイント（日付検索・レース詳細）
- [x] 騎手・調教師の勝率/複勝率集計
- [x] 馬体重変動アラート（前走比±10kg以上で警告）
- [x] 血統データ表示（父・母・母父）
- [x] 過去成績データ（直近5走）
- [x] AI予想プロンプトへのJRDBデータ自動付与
- [x] レース予想画面でのJRDB自動入力ボタン
