# プロジェクト概要

## 目的

Claude APIを活用した競馬AI予想WebUI。レース情報を入力すると、全馬券種の推奨買い目を提案。結果の蓄積・馬券種別の成績分析が可能なパーソナル予想ツール。

## ターゲットユーザー

- 自分専用（個人利用、認証なし）

## スコープ

### Phase 1（MVP）

- レース情報の手動入力（出馬表）
- Claude API によるAI予想生成
- 予想結果表示（AI偏差値・推奨度・根拠・推奨買い目）
- 全馬券種対応（単勝/複勝/馬連/馬単/ワイド/三連複/三連単）
- レース結果の手動入力・収支計算
- 馬券種別の成績集計（的中率・回収率）
- ダッシュボード（成績サマリー）

### Phase 2

- 競馬データAPI連携（JRA-VAN / JRDB等）による自動取得
- 予想ロジック（プロンプト）の管理・切り替え
- 成績分析ダッシュボード（グラフ表示）
- CSV出力

### Phase 3

- 結果の自動取得
- オッズ歪みチャート等の高度な可視化

## 成功指標

- 予想の蓄積数
- 馬券種別の回収率推移の可視化
- 予想ロジック変更前後の成績比較
