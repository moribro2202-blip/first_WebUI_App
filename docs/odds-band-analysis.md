## 考察と疑問点

### 12-15倍帯の145.9%は本物か？
- R数946は統計的には一定のサンプルサイズだが、6年分を2倍刻みで分割した12区間の1つであり、多重比較の問題がある
- 6年全てプラスだが、年別のブレは114%-183%と大きい
- 隣接帯（10-12倍: 117%, 15-18倍: 120%）も高いことから、12-15倍だけが偶然高い可能性は否定できない

### 10-30倍帯の130.7%はより信頼できるか？
- R数2,832で十分なサンプルサイズ
- 6年全てプラス（106%-185%）
- 10倍刻みの大きな帯なので多重比較のリスクが低い
- 0-10倍帯（114.7%）との差が16ptあり、統計的にも意味がある可能性
- 10-12倍, 12-15倍, 15-18倍, 18-22倍の全てがプラスであり、帯域内で一貫している

### なぜ10-30倍帯が高いのか（仮説）
1. **市場とモデルの乖離が最大**: M7が「堅い」と予測するが、市場は10-30倍の配当をつける＝市場がM7の3頭目を過小評価
2. **0-10倍は市場も正確**: 堅いレースは市場参加者も正しく評価しているため、配当が低くエッジが薄い
3. **30倍以上は予測困難**: M7の精度が追いつかず、的中率が急落
4. **テラ銭の影響**: 低配当帯（0-10倍）ではテラ銭25%の影響が相対的に大きい

### 分散リスク
- 10-30倍帯は的中率9.6%（全体13.5%より低い）
- 最大連敗56回（現行49回）
- 年別σ=26.3（現行18.1より大きい）
- 的中時の配当が大きい分、ブレも大きい

## 検証してほしいポイント

1. **12-15倍帯の回収率145.9%は過学習（多重比較）の産物か、それとも構造的なエッジか？**
2. **10-30倍帯の130.7%は信頼できるか？** 6年全プラスだが、サンプル分割によるバイアスはないか？
3. **ハイブリッド戦略（全レース＋12-15倍追加ベット）は合理的か？** 12-15倍が偶然なら効果がない
4. **市場効率性の観点から、なぜ中配当帯（10-30倍）にエッジが集中するのか？** この構造は将来も持続するか？
5. **最大連敗56回（10-30倍）は実運用に耐えられるか？** 資金管理上の問題は？

## モデル仕様（参考）

- M7 Full Combined: IDM + 騎手指数 + 馬場適性 + 脚質 + 体重安定性 + 距離/馬場適性
- Stern補正: λ1=0.9, λ2=0.8
- PredBlend ≤ 8 フィルタ
- α=0.50（モデル50% + 市場50%）
- 三連複◎○▲ 1点、固定額ベット
- データ: JRDB 2021-2026（6年間）
- 外部監査（Fable5）対応済み、IDMリーク検証済み
