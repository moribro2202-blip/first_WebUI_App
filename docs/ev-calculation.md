# 競馬AI 期待回収率（EV）計算ガイド

## 0. 全体像

期待回収率の計算は、次の4ステップで構成される。

1. モデルのスコアを**単勝勝率 `p_i`** に変換する
2. `p_i` から**着順の同時確率**を作り、全券種の的中確率を導出する
3. 券種ごとの**市場確率（オッズ）**と突き合わせ、EVを計算する
4. EVが閾値を超えた買い目だけを、ケリー基準で購入する

式そのものより「確率の精度」と「検証の厳密さ」が全て。

---

## 1. 基本式と控除率

### 期待回収率（EV）

```
EV = 的中確率 p × 払戻倍率 O
```

- `EV > 1.0` が損益分岐点
- 推定誤差を考慮し、実務上の購入閾値は **1.1〜1.2** に置く

### 券種別の払戻率（何もしなければこの回収率に収束する）

| 券種 | 払戻率 |
|---|---|
| 単勝・複勝 | 80.0% |
| 枠連・馬連・ワイド | 77.5% |
| 馬単・3連複 | 75.0% |
| 3連単 | 72.5% |
| WIN5 | 70.0% |

- 下の券種ほど控除率は不利だが、**市場の値付けが粗い**ため歪みも残りやすい

---

## 2. スコア → 勝率への変換

評価点をそのまま確率扱いしない。レース内で合計1になるよう**条件付きロジット（Luceモデル）**で変換する。

```
p_i = exp(s_i) / Σ_j exp(s_j)
```

- `s_i`：馬iの強さスコア
- 学習：各レースの1着馬の対数尤度を最大化
- 頭数の変動を自然に扱えるため競馬向き

---

## 3. 着順確率モデル（Harville）と全券種への展開

### 基本形

i→j→k の順に入る確率：

```
P(i→j→k) = p_i × p_j/(1-p_i) × p_k/(1-p_i-p_j)
```

### 券種別の的中確率

| 券種 | 計算方法 |
|---|---|
| 馬単 i→j | `p_i × p_j/(1-p_i)` |
| 馬連 {i,j} | `P(i→j) + P(j→i)` |
| 3連単 i→j→k | 上の3項の式そのもの |
| 3連複 {i,j,k} | 6通りの順列を全て加算 |
| 複勝 i | iが1〜3着に入る全経路を加算 |
| ワイド {i,j} | i, j が両方3着以内に入る確率 |

- 18頭立ての3連単でも 18×17×16 = 4,896通り。**全列挙で問題ない**

### Harville補正（必須）

Harvilleは**人気馬の2・3着確率を過大評価**する既知のバイアスを持つ。

Stern / Henery 型のべき乗割引で補正する：

```
2着の条件付き確率 ∝ p_j^λ1    （λ1 ≈ 0.8 から開始）
3着の条件付き確率 ∝ p_k^λ2    （λ2 ≈ 0.6 から開始）
```

- λ は実データの対数尤度最大化でフィットする
- **λ=1のまま3連系のEVを計算すると、人気サイドを買いすぎる方向に必ず外れる**

---

## 4. 市場確率の抽出とブレンド

### オッズ → 市場の暗黙確率

```
π_i = (1/O_i) / Σ_j (1/O_j)
```

- 分母で正規化して控除率を除去（1/O の単純合計は約1.25になる）

### モデル確率とのブレンド

```
ln p_i ∝ α · ln p_model,i + (1-α) · ln π_i    （最後に正規化）
```

- `α` は検証データで最適化
- 経験的に **α = 0.1〜0.3** 程度と小さい = 市場は既に大半を織り込んでいる

### プールごとに市場確率を作り直す

- 馬連プールの資金分布は単勝プールと異なる。**券種ごとに別々に π を計算**する
- クロスプール裁定は、単勝単体より歪みが素直に残りやすい

### 複勝・ワイドの注意点

- プールを的中3組で分け合うため、**払戻が「下限〜上限」のレンジになる**
- EV計算はレンジ下限を使う（保守的）

---

## 5. 賭け金の決め方（ケリー基準）

```
f = (p × O - 1) / (O - 1)
```

- `f`：資金に対する投入比率
- フルケリーは推定誤差に極端に弱いため、**1/4ケリー程度**に落とす
- 単勝で `f > 0.05` が出たら、モデルの確率過信を疑う

### 買い目の選び方

- 「全通り計算 → EVが閾値を超えた点だけ買う」が原則
- 合成オッズ：`1 / Σ(1/O_i)`

---

## 6. 検証（バックテスト）の原則

### 時系列分割

- ランダム分割は厳禁。**必ず時間で切る**

### オッズの扱い

- パリミュチュエルのため確定オッズと購入時オッズは異なる
- 結果を1割程度割り引いて解釈

### 必要サンプル数（分散の壁）

| 券種 | 1点あたりσ（概算） | ROI±5%判定に必要な点数 |
|---|---|---|
| 単勝 | 約3 | 約3,600 |
| 馬連 | 8〜10 | 約3万 |
| 3連複 | 15〜25 | 約10万 |
| 3連単 | 50〜100 | 約100万〜 |

### ROI以外の評価指標

- **対数損失（log loss）**でモデルを比較する
- **キャリブレーションプロット**で精度確認

---

## 7. 実装の推奨順序

1. SEDパーサーの着順欠損を修正
2. 現行モデルのキャリブレーション確認
3. Harvilleで全券種の確率を出す関数を実装
4. λ（Stern/Henery補正）を実データでフィット
5. 複勝・ワイドの期待払戻（レンジ）を正しく扱う
6. 券種ごとの市場確率を抽出し、モデル確率とブレンド（αを最適化）
7. EV閾値＋1/4ケリーで運用ルール化

### データ拡充の優先度

- 血統・騎手/調教師成績・枠番・性別は**市場がほぼ織り込み済み**
- 相対的に織り込みが甘いのは **調教データ（CHAファイル）** と **当日馬体重（TYBファイル）**
