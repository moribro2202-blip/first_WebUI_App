# M7 Full Combined 競馬予測モデル 技術仕様書

## 1. モデル概要

JRDBデータを用いた三連複（3着以内の3頭の組み合わせ）予測モデル。
2021-2026年の6年間、17,842レースでバックテスト済み。

| 項目 | 値 |
|------|-----|
| モデル名 | M7 Full Combined |
| Harville補正 | Stern λ1=0.9, λ2=0.8 |
| 推奨フィルタ | PredBlend ≤ 8（Stern補正後の予想三連複オッズ8倍以下） |
| 推奨α | 0.50 |
| 通算回収率 | 131.6%（α=0.50, Stern 0.9/0.8, PB≤8） |
| 年間レース数 | 約890R |
| キャリブレーション | 0.92x（予測と実測の一致度） |
| 統計的有意性 | t=5.23, 95%CI: [+19.5%, +43.0%] |
| 外部監査 | Claude Fable5評価済み、全6指摘対応完了 |

## 2. データソース

| データ | ファイル | 内容 | タイミング |
|--------|---------|------|----------|
| IDM（スピード指数） | TYB | JRDB独自のスピード指数 | レース当日朝（レース前） |
| 騎手指数 | TYB | JRDB独自の騎手評価 | レース当日朝 |
| 脚質 | KYI | 逃げ/先行/差し/追込/好位差し/自在/後方 | 出走表公開時 |
| 馬場状態 | BAC | 良/稍重/重/不良 | レース当日発表 |
| 前日単勝オッズ | OZ | JRA前日発売オッズ | レース前日 |
| 三連複前日オッズ | OT | 三連複の前日オッズ（払戻計算用） | レース前日 |
| 過去成績 | SED | 着順・タイム・馬体重・コーナー通過順 | 過去レースのみ使用 |
| 馬基本情報 | UKC | 性別・生年・父馬・母馬 | マスタデータ |

**全データはレース前に入手可能。確定オッズ（レース後データ）は一切使用していない。**

## 3. スコアリング関数

各出走馬に対して以下のスコアを計算する:

```
Score = IDM + 騎手指数 + 馬場適性 + 脚質補正 + 体重安定性 + 距離適性 + 馬場適性
```

### 3.1 IDM（ベーススコア）
- JRDBが独自に算出するスピード指数（偏差値形式、平均50）
- 過去のレースタイムを馬場差・ペース差で補正した実力値
- これが最も予測力の高い単一特徴量

### 3.2 騎手指数
- JRDBが算出する騎手の当日評価値
- 騎手の技量だけでなく、その馬との相性も考慮

### 3.3 馬場状態適性
- 当日の馬場状態（良/稍重/重/不良）における、その馬の過去成績
- 過去3走以上のデータがある場合に適用
- 計算: `(6 - 平均着順) × 1.5`

### 3.4 脚質補正
- 予想される脚質に基づく固定ボーナス
- 逃げ: +1.0, 先行: +0.5, 好位差し: +0.3, 差し: 0, 追込: -0.3, 自在: +0.3, 後方: -0.5
- JRA全体で先行馬が統計的に有利であることを反映

### 3.5 馬体重安定性
- 直近3走の馬体重変化を確認
- ±4kg以内（安定）: +0.5
- ±10kg超（大幅変動）: -1.5
- 急激な体重変化は体調不良のシグナル

### 3.6 距離適性
- 当日の距離±200mでの過去成績（直近5走）
- 過去2走以上のデータがある場合に適用
- 計算: `(6 - 平均着順) × 0.8`

### 3.7 馬場（芝/ダート）適性
- 当日と同じ馬場（芝 or ダート）での過去成績
- 計算: `(6 - 平均着順) × 0.8`

## 4. 確率変換とブレンド

### 4.1 モデル確率（softmax）
```
model_prob[i] = exp((score[i] - 50) × 0.15) / Σ exp((score[j] - 50) × 0.15)
```
- scale=0.15: スコア差をどの程度確率差に変換するかの温度パラメータ

### 4.2 市場確率（favorite-longshot bias補正）
```
raw_prob[i] = (1/odds[i]) / Σ(1/odds[j])
market_prob[i] = raw_prob[i]^1.03 / Σ raw_prob[j]^1.03
```
- β=1.03: 人気馬の過小評価（favorite-longshot bias）を補正

### 4.3 ブレンド（log-linear）
```
blended[i] = exp(α × ln(model[i]) + (1-α) × ln(market[i]))
```
- α=0.50-0.70: モデルと市場の重み（モデル50-70%、市場30-50%）
- 幾何平均ベースのブレンドにより、両者の極端な予測を緩和

## 5. 三連複確率の推定（Stern補正付きHarvilleモデル）

上位3頭の組み合わせ確率をStern補正付きHarvilleモデルで計算:

```
P(trio {A,B,C}) = Σ P(perm) for all 6 permutations of (A,B,C)

P(A→B→C) = p_A/S × (p_B^λ1)/S2 × (p_C^λ2)/S3
  where S = Σ p_i, S2 = Σ p_j^λ1 (j≠A), S3 = Σ p_k^λ2 (k≠A,B)

λ1 = 0.9 (2着補正), λ2 = 0.8 (3着補正)
```

- 素のHarville（λ=1）は人気馬の2・3着確率を過大評価する（キャリブレーション0.72x）
- Stern補正（λ1=0.9, λ2=0.8）でキャリブレーション0.92xに改善
- 外部監査（Claude Fable5）の指摘により追加

予想三連複オッズ:
```
PredBlend = (1 / P(trio)) × 0.75
```
- 0.75 = テラ銭（控除率25%）を反映

## 6. フィルタ（賭けるレースの選別）

### 6.1 PredBlend ≤ 8 フィルタ（Stern補正後）
- Stern補正済みHarvilleで計算した予想三連複オッズが8倍以下のレースのみに賭ける
- 意味: モデルが「上位3頭の確率が高い」と判断するレース
- 年間約890レース（全体の約30%）
- OTオッズ > 500倍のレースは異常値として除外

### 6.2 フィルタの効果（Stern 0.9,0.8）
| 条件 | 回収率 | R数 |
|------|--------|-----|
| フィルタなし | ~100% | 17,842 |

## 9. モデルの強みと弱み

### 強み
1. **JRDBのIDMが市場に完全に織り込まれていない** — 独自のエッジ源
2. **PredBlendフィルタにより確信度の高いレースだけ選別** — 的中率15.9%
3. **パラメータ非依存** — αを変えても全て122%以上
4. **リアルタイム運用可能** — 確定オッズ不要、モデル計算のみで判断
5. **外れ値非依存** — top10的中を除いても120%以上

### 弱み
1. **2022年がマイナス（96.7%）** — 6年中1年は負ける可能性
2. **5-6月と11-12月が弱い** — 季節性あり
3. **JRDBデータへの依存** — JRDBがサービス変更/終了した場合のリスク
4. **三連複テラ銭25%** — 高い控除率をモデルで超えている前提

## 10. 既知の問題

1. **OTデータの異常値**: 一部レースで三連複オッズ9999.8倍が記録されている（未発売 or データエラー）。PredBlend≤5フィルタにより自然に除外されるが、PredBlend≤10以上では影響大
2. **2020-2021年のコロナ影響**: 無観客開催によるオッズ構造の変化で、2021-2022年の学習データの質が低下
3. **OTオッズの前日/確定混在**: OT1（前日）とOT2（確定）が混在。確定オッズでの再計算ではRRの差は±1pt以内

## 11. 実運用フロー

```
1. レース前日: OZファイルから前日単勝オッズ取得
2. レース当日朝: TYBファイルからIDM・騎手指数取得
3. 馬場状態確認: BAC or JRA発表
4. M7スコア計算 → softmax → 市場確率とブレンド
5. Harvilleモデルで三連複確率計算 → PredBlend算出
6. PredBlend ≤ 5 のレースのみ三連複◎○▲を1万円購入
7. レース結果確認 → 収支記録
```
