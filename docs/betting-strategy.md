# M7 運用戦略: 20万円スタート段階ベットアップ

## 概要

初期資金20万円から段階的にベット額を上げ、MAX2万円/Rまで引き上げる戦略。
6年間のバックテストで20万→2,952万円（+2,932万円）。

## ベットアップルール

残高に応じて自動的にベット額を変更する。残高が下がればベット額も下がる。

| 残高 | ベット額 | 目安 |
|------|---------|------|
| 0円〜 | 2,000円 | 開始直後・回復時 |
| 20万円〜 | 3,000円 | 元本回復 |
| 35万円〜 | 5,000円 | 利益+15万 |
| 60万円〜 | 7,000円 | 元本3倍 |
| 100万円〜 | 10,000円 | 100万到達 |
| 150万円〜 | 15,000円 | 150万到達 |
| 250万円〜 | 20,000円 | MAX |

## 運用ルール

- **賭け方**: 三連複◎○▲ 1点のみ
- **フィルタ**: PredBlend ≤ 8（予想オッズ8倍以下のレースだけ賭ける）
- **モデル**: M7 Full Combined（v25 Stern補正）
- **ベット額の決定**: その時点の残高で上の表を参照
- **残高が下がったら**: ベット額も自動で下がる（破産防止）

## 注意事項

1. **バックテスト上の結果**であり、将来の利益を保証しない
2. **最初の2ヶ月はマイナスの可能性が高い**（我慢が必要）
3. **最大52%のドローダウン**を精神的に耐えられるかが鍵
4. 残高が下がってもルールに従いベット額を下げること（感情的な増額禁止）
5. **モデルの凍結**を守り、パラメータを変えない
6. まずペーパートレードで2ヶ月検証してから実運用に移行
