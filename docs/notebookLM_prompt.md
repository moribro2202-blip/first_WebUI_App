# 競馬AIで市場に勝てるか — 個人開発者の検証記録

## はじめに

競馬の馬券を買うと、平均して賭けた金額の約80%しか戻ってこない。残りの20%はJRA（日本中央競馬会）の取り分だ。つまり、何も考えずに買い続ければ確実に負ける。

では、AIを使えばこの20%のハンデを乗り越えて、プラス収支にできるのか？

この文書は、個人開発者がその問いに正面から取り組んだ記録だ。結論から言うと、「わずかに勝てる。ただし、思っていたよりずっと薄い利益で、しかもそれは皆が想像するような"AIが勝ち馬を当てる"話ではなかった」。

---

## 1. 競馬の市場はどれくらい賢いか

競馬のオッズは、大勢の人がお金を賭けた結果として決まる。1番人気（最もオッズが低い馬）の勝率は約33%で、オッズから逆算した確率とほぼ一致する。つまり、市場はかなり正確に各馬の勝率を見積もっている。

これが「市場は効率的」と言われるゆえんだ。AIで勝つには、この市場が見落としている情報を見つけなければならない。

### モデルの考え方

一からオッズを予測するのではなく、「市場の見積もりをベースに、市場が織り込んでいない差分だけを足す」設計にした。

具体的には：
- **市場の見積もり（オッズから計算した確率）** を土台にする
- そこにAI（LightGBM）が「市場が見落としている要素」を足す
- 足した結果の確率 × オッズ が1.0を超えれば、期待値がプラス（=買い）

この「期待値（EV）」という考え方が全ての基本になる。たとえばオッズ10倍の馬の真の勝率が12%なら、EV = 0.12 × 10 = 1.2。100円賭けると平均120円返ってくる計算だ。

## 2. 特徴量とは何か — AIに「何を見せるか」

AIは与えられたデータから自分でパターンを見つけて学習する。このとき、AIに渡すデータの1つ1つを「特徴量」と呼ぶ。料理に例えると、AIが料理人で、特徴量は食材。どんな食材を渡すかで、出来上がる料理の質が変わる。

### 私のモデルの特徴量（24個）

私のモデルが使っている特徴量は24個。競馬AI界隈では少ないほうだと思う。以下がその全リスト。

|--------|------|--------|

| expert_resid | 前日オッズと直前オッズの乖離。「前日の予想」と「直前の現実」のずれ | ★★ |

**馬の実力指標**

### 他の開発者との違い

ある方が特徴量170個を公開されていた。その方は過去5走分のデータを「真Zスコア」（走破タイムの予測値と実績のズレ）として持ち、距離別に5台のAIを使い分けている。

対して私のモデルは24個とかなり少ない。これは設計思想の違いで、私のモデルは**馬の能力よりも「市場の歪み」を検出する**ことに特化している。馬の強さの予測はオッズ（市場）に任せ、AIは「オッズに反映されていない差分」だけを拾う。

### 3つのモデルの比較

私のモデル以外に、特徴量を公開されている2つの競馬AIモデルがある。それぞれアプローチが大きく異なるので比較してみる。

**モデルA（170個特徴量モデル）** — 「真Zスコア」という独自指標が特徴的。実際のレースデータから走破タイムを予測し、その予測と実績のズレ（偏差）を指標化している。PCI（ペースチェンジインデックス）などのペース系指標も充実。芝短距離/芝中距離/芝長距離/ダート短距離/ダート中長距離の5台のAIを使い分ける。

**モデルB（SQLクエリ型モデル）** — 地方競馬（大井、川崎、園田など14場）のキャリアデータまで含む網羅的なモデル。場ごとの勝利数・連対数・複勝数を個別に持ち、「この馬は大井で3勝、川崎で1勝」のように場の適性を細かく見る。また「予想先行指数」「予想タイム指数」などの事前予測指数を偏差値・順位付きで持つのも特徴。過去5走分のフルデータ（レース条件＋結果＋指数＋オッズ）を結合する大規模なSQL。

| 比較項目 | 私のモデル | モデルA（170個） | モデルB（SQL型） |
|---------|-----------|---------------|---------------|
| 特徴量数 | **24個** | 170個 | 推定300個超 |
| 過去走データ | 平均値のみ | 過去5走×各26指標 | 過去5走のフル詳細 |
| 独自指数 | なし | 真Zスコア | 予想タイム指数等 |
| AIの台数 | 1台 | 5台 | 不明 |
| 核心特徴量 | **直前オッズ変動** | パフォーマンス指標 | 場別キャリア＋指数 |
| 目的 | 市場の歪み検出 | 馬の能力予測 | 馬の能力予測 |
| 地方競馬 | 非対応 | 非対応 | **14場対応** |
| オッズ活用 | **直前の時系列変動** | なし | 確定オッズ+合成オッズ |

### 3つのアプローチの違いを料理に例えると

- **モデルA** は「この馬は前回のレースで予想より0.3秒速く走った。切れ味指数も高い。だから強い」と、**馬そのものの実力**を精密に測ろうとしている。シェフが食材（馬）の品質を極限まで見極めるアプローチ。

- **モデルB** は「この馬は大井で3勝してる。重馬場でも2勝。予想タイム指数の偏差値は62」と、**あらゆる角度からデータを集め**て判断する。百科事典的アプローチ。

- **私のモデル** は「この馬のオッズが、さっきまで20倍だったのに今15倍に下がった。誰かが大金を入れた。何か知ってるのでは？」と、**他の参加者の行動**を見ている。食材の品質ではなく、**他のシェフが何を仕入れたか**を観察するアプローチ。

### 面白い特徴量のアイデア（参考モデルから学べること）

**モデルAの「真Zスコア」は秀逸な設計**

普通は「前走タイム1分35秒」をそのまま使うが、タイムはコースや馬場で全然違う。真Zスコアは「このコース・この馬場なら1分35秒5くらいが普通。この馬は1分35秒0で走った。つまり普通より0.5秒速い」と、条件を揃えた上での偏差を出している。これなら東京芝1600mの1分33秒と中山芝2000mの2分00秒を同じ尺度で比べられる。

**モデルBの「合成オッズ」は要注目**

単勝だけでなく、馬連やワイドなど複数の券種のオッズから「市場が本当に思っている確率」を逆算する。単勝オッズと馬連オッズの整合性が取れていない馬がいれば、それは市場内部の歪み。私のモデルの「市場の歪み検出」アプローチと相性が良い可能性がある。

**モデルBの「休養間隔」「クラス変動」「距離増減」**

- 休養間隔：実は私のモデルでも検証済み（v8）で回収率が微改善（+5pt）した。ただし市場はすでに知っている情報なので、エッジとしては弱い
- クラス変動：前走から格上げか格下げか。直感的にはクラスが下がった馬は有利だが、オッズもそれを反映する
- 距離増減：前走からの距離変化。延長・短縮で得意な馬がいる

これらは「馬の実力予測の精度を上げる」のには有効だが、私の検証では**市場がすでに織り込んでいる**ため回収率改善にはつながらなかった。

### 距離別・馬場別にAIを分けるべきか

モデルAは芝/ダート×距離で5台に分けている。私は1台で全レースを処理している。

分ける利点は、距離や馬場によって重要な特徴量が変わること（短距離では先行力、長距離ではスタミナなど）。モデルAの開発者も「それぞれに必要な特徴量が違う」と述べている。

一方、分けるとデータが1/5になり、各AIの学習量が減る。私のモデルは市場の歪み検出が目的で、距離による歪みの構造差は小さかったので1台で処理している。ただし、馬の能力予測に特化するなら分けたほうが良い可能性はある。

### 「特徴量の数」と「勝てるかどうか」は別の話

ここが最も重要なポイント。24個でも170個でも300個でも、**市場が知っていることの精度を上げているだけなら、回収率は80%に向かって収束する**（控除率20%の壁）。

回収率100%を超えるには、「市場がまだ織り込んでいない情報」が必要。私の場合、22個の基本特徴量に「直前オッズ変動」を1つ足しただけで回収率が91%→108%に跳ねた。逆に言えば、残りの22個は回収率にほとんど寄与していない（市場が知っていることの再確認にすぎない）。

ただし、これは「馬の能力予測は意味がない」ということではない。精密な能力予測があれば、オッズとの乖離をより正確に測定でき、投票の精度が上がる可能性はある。モデルAの真Zスコアのような指標を私のモデルに組み込めば、「市場の歪み」をより精密に検出できるかもしれない。今後の検証課題だ。

## 3. 最初の大失敗：嘘のデータでバックテストしていた

モデルを組んで過去データで検証したところ、回収率120%超え。「やった、勝てる！」と思った。

ところが、よく調べるとデータ自体が嘘だった。

JRA-VANが提供する「発走1分前のオッズ」を使っていたのだが、2015〜2021年のデータは実際には**レース確定後のオッズ**（＝結果が出た後の数字）が「1分前」として記録されていた。つまり、答えを見てから問題を解いていたようなもの。

| 期間 | 「1分前オッズ」の正体 |
|------|---------------------|
| 2015-2021年 | 実は確定後オッズ（カンニング状態） |
| 2022年〜 | 本物の発走1分前オッズ |

この発見で、初期の好成績は全て無効になった。2022年以降のデータだけで検証し直す必要があった。

**教訓：データの中身を確認しないバックテストは、ただの自己満足。**

## 4. 公開データだけでは市場に勝てない

気を取り直して、2022年以降のクリーンなデータで検証。前述の22個の基本特徴量（IDM、騎手勝率、過去成績、距離適性など）を使った結果：

**回収率91%**。市場の80%よりは良いが、100%には届かない。

つまり、新聞やデータベースに載っている情報は、市場がすでに織り込んでいる。170個の特徴量で精密に予測しても、それが市場が知っていることの精度改善なら、回収率は100%を超えない可能性がある。

## 5. エッジの発見：最後の数分間の「資金の流れ」

転機は「オッズの時間変化」に着目したことだった。

発走5分前と3分前のオッズを比較すると、一部の馬でオッズが急激に下がる（＝大量の資金が投入される）ことがある。この「直前のオッズ変動（move_5to3）」を特徴量に追加したところ：

| 設定 | 回収率 |
|------|--------|
| 22特徴量のみ（変動なし） | 91% |
| + 直前オッズ変動 | **108〜115%** |

なぜこれが効くのか。締切直前に大きな資金を投入する人は、何らかの情報（調教の状態、馬の体調など）を持っている可能性が高い。市場全体がそれを完全に織り込む前の数分間に、わずかな「情報の非対称性」が生まれる。

このモデルが捉えているのは、「賢い資金の動き」だ。

これは170個モデルのように馬の能力を精密に測る方向とは全く異なるアプローチだが、回収率に直結するのはこちらだった。

## 6. 「勝てる」の中身：実際の数字

### 2つのフェーズ

検証は2段階で進んだ。最初は単勝のみ、次に三連複・三連単を加えた2段階モデル。

**Phase 1：単勝のみ（回収率114%）**

| 項目 | 数値 |
|------|------|
| 年間の投票数 | 約1,570点 |
| 的中率 | 7.9%（約13回に1回） |
| 回収率 | 114% |
| 年間利益（1点1万円） | +235万円 |

**Phase 2：三連複+三連単（回収率127.6%）**

| 項目 | 数値 |
|------|------|
| 対象レース | 全レースの57.5%（約21R/日） |
| 的中率 | 14.6%（**7Rに1R**で何か的中） |
| 平均点数/R | 10.8点 |
| 平均費用/R | 1,078円 |
| 回収率 | **127.6%** |
| 利益（3年合計、1点100円） | **+159万円** |

### 年別の成績（1点100円の場合）

| 年 | レース数 | 投資額 | 回収率 | 損益 |
|----|---------|--------|--------|------|
| 2024年 | 2,142R | 233万円 | 129.5% | **+69万円** |

3年とも120%以上。ただし、これはバックテスト（過去データでの検証）であり、実運用では遅延やスリッページでこれより下がる可能性がある。

## 7. ある1日の体験：85%はハズレ、でもトータルでプラス

2段階モデルの1日（2026年8月2日）を再現してみる。

この日は18レースが対象。投資9,000円（平均500円/R）。

**ほとんどのレースはハズレ:**
- 札幌1R：トリオ5組10点1,000円 → 全ハズレ（-1,000円）
- 札幌3R：1組2点200円 → ハズレ（-200円）
- 札幌4R：1組2点200円 → ハズレ（-200円）
- ...16レース連続ハズレ → 累計-8,000円

**しかし2レースで的中:**
- 札幌5R：◎2番を1着に固定、トリオ2-3-7で三連単2-7-3が的中。**113.7倍 = +10,370円**
- 新潟1R：◎7番を1着に固定、トリオ4-5-7で三連単7-5-4が的中。**66.1倍 = +6,210円**

**この日の合計：投資9,000円 → 払戻17,980円 → 利益+8,980円（ROI 200%）**

これが日常。85%のレースは負ける。でも当たれば三連単の高配当（50〜200倍）で一気に回収する。月単位では73%が黒字月になる。

### リスク指標

| 指標 | 値 |
|------|------|
| 黒字月の割合 | **73%**（33ヶ月中24ヶ月） |
| 最高月 | **+22.6万円** |
| 最悪月 | **-11.1万円** |
| 最大ドローダウン | 11.1万円 |
| 最大連敗月 | **2ヶ月**（すぐ回復） |

## 8. なぜ大穴はもっと儲からないのか — Favorite-Longshot Bias

直感的には「大穴を的中させれば大儲け」だが、現実は違う。

| オッズ帯 | 市場が暗示する勝率 | 実際の勝率 | 市場の精度 |
|---------|-----------------|----------|----------|
| 1-2倍（本命） | 61% | 50% | わりと正確 |
| 5-8倍（中穴） | 16% | 13% | まあまあ |
| 35-60倍（大穴） | 2.2% | 1.6% | 過大評価 |
| 100倍超（超大穴） | 0.5% | 0.3% | 大幅に過大評価 |

大穴ほど市場は勝率を過大評価している。これを「Favorite-Longshot Bias」という。人は「万馬券」の魅力に引かれて、大穴の馬券を買いすぎる傾向がある。

このバイアスのため、大穴帯でAIがEV1.2以上と判定しても、実際にはそこまで妙味がないケースが混ざる。モデルにはこのバイアスを補正する較正関数を組み込んでいる。

## 9. 「EV1.2以上」の落とし穴 — Winner's Curse

AIが「この馬はEV1.3だ！買い！」と判断したとき、2つの可能性がある：

1. **本当にEV1.3の馬**（モデルが正しい）
2. **実際はEV1.0だが、たまたま誤差で高く出た馬**（ノイズ）

EV1.2以上でフィルタをかけると、この2つの混合を選ぶことになる。結果として、選んだ馬の実際の回収率は、AIの予測よりも系統的に低くなる。これを**Winner's Curse（勝者の呪い）**という。オークション（競売）で「最も高い値をつけた人は、たいてい払いすぎている」のと同じ原理だ。

| EV帯 | AIの予測勝率 | 実際の勝率 | 比（Curse度） |
|------|-----------|----------|-------------|
| 1.0-1.1 | 15.7% | 13.8% | 0.88 |
| 1.2-1.5 | 11.6% | 9.6% | **0.82** |
| 1.5超 | 10.5% | 6.8% | **0.65** |

EV1.2-1.5帯では、AIの予測の**82%**しか的中しない。このバイアスを踏まえると、損益分岐は EV ≈ 1/0.82 ≈ 1.22。安全マージンを取って**EV1.20**を投票の閾値に設定している。

## 10. 三連複・三連単でも勝てた — 2段階モデル

当初は「単勝以外はエッジなし」と結論づけていたが、2つのモデルを組み合わせることで連系でも安定したエッジを確認できた。

### 2段階モデルの仕組み

**第1段階：三連複モデル（どの3頭が3着以内か）**

Stern-Harville変換（単勝確率から3頭の組み合わせ確率を導出する数学的手法）をベースに、LightGBMで残差を補正する。上位8頭のC(8,3)=56通りの組み合わせからEV（期待値）が1.0以上のものを選ぶ。

**第2段階：単勝モデル（3頭のうち誰が1着か）**

第1段階で選んだ3頭の中で、単勝モデル（move_5to3が核心特徴量）が勝率を予測し、◎（1着候補）と○（2着候補）を決定する。

この2段階を使い分ける：
- ◎が実際に1着だった確率：**49.1%**（ランダムの33.3%を大きく上回る）
- ◎○のどちらかが1着：**80.8%**

### 頭数で券種を切り替える

検証の結果、出走頭数によって最適な券種が異なることが分かった。

| 条件 | 買い方 | 費用/トリオ | 理由 |
|------|--------|----------:|------|
| **12頭以上** | 三連単1-2着流し + 三連複（保険） | 500円 | 多頭数は荒れやすく配当大 → 三連単有利 |
| **12頭未満** | 三連複のみ | 100円 | 少頭数は堅い → 1着予測が難しく三連複が安全 |

「1-2着流し」とは、◎と○のどちらかを1着に固定して残りの2頭の順列を買う方法。4通りの三連単（◎→○→▲、◎→▲→○、○→◎→▲、○→▲→◎）を買う。これに三連複1点を保険として加え、▲が1着に来ても回収できるようにする。

### 大失敗からの教訓：三連単170%はバグだった

## 11. EV閾値をもっと下げれば点数が増えて儲かるのでは？

EV閾値を1.20から1.10に下げると、投票数は年1,570点→2,350点に増える。一見、薄利多売で利益が増えそうだ。

しかしFable（外部監査AI）はこれを明確に否定した：

> EV1.0〜1.15帯の限界回収率はほぼ100%。この帯を足しても利益はほとんど増えず、分散と運用負荷が増えるだけ。しかも1日の投票上限の枠の中で、低EVの賭けが高EVの賭けを押し出す。薄利多売は、利が本当に薄いときは多売の意味がない。

実際、この戦略の利益の3分の2はEV1.4超のごく少数の投票から生まれている。つまり**少数の高EV馬で稼ぎ、多数の中EV馬はトントン**、という構造。閾値を下げて中EV帯を増やしても、利益にはほとんど寄与しない。

## 13. 学んだこと

### AIは馬を当てているわけではない

的中率7.9%。**13回に1回しか当たらない**。それでも勝てるのは、市場（オッズ）が反映していない「最後の数分間の情報」を拾えているから。AIは馬の強さを予測しているのではなく、**市場の値付けの歪み**を検出している。

### 特徴量の数より「何を見るか」が大切

22個の特徴量でも170個の特徴量でも、市場が知っていることを精密に再現するだけなら回収率100%を超えない。大切なのは「市場がまだ知らない情報」を特徴量に入れること。私の場合はそれが「直前のオッズ変動」だった。

### エッジは驚くほど薄い

回収率114%は、100円賭けて平均114円戻ること。14円の利益。この14円を年間1,570回繰り返して、ようやく年+235万円。しかも標準偏差が186万円あるので、年によっては赤字になる。

### 分散との戦い

この戦略の最大の敵は「負けているときに止めてしまうこと」。68連敗は普通に起きる。最大ドローダウン199万円も想定内。これを「異常事態」と誤認して止めると、その後の回復を取り逃がす。

### データを信じすぎてはいけない

偽のデータでバックテストして120%超えと喜んでいた経験は、データの怖さを教えてくれた。「結果が良すぎるときは、まずデータを疑え」。

### 触れば触るほど悪くなる

EV閾値を0.01刻みで最適化すると、過去データに対して最高の閾値が見つかる。しかしそれは「ノイズの山の頂点」であり、翌年には別の場所に山が立つ。パラメータは理論で決めて固定するのが正解。

## 14. 結論：2段階モデルで回収率127%

外部監査AI（Fable5）の単勝に対する当初の評価：

> 2022年以降、発走1〜3分前の判定で、単勝EV1.2以上・2〜40倍帯の回収率は108〜117%。エッジは実在するが薄い。**勝てる事業ではなく、勝てる趣味。**

その後、三連複モデル＋単勝モデルの2段階構造を開発。三連単170%のバグを外部監査で発見・修正し、最終的に：

> **回収率127.6%、年間利益+53万円（1R予算3,000円）。** 3年とも121〜134%で安定。黒字月73%、連敗月は最大2ヶ月。レースの57%が対象で、7Rに1Rで的中。

単勝のみ（112%、利益+5万）から大幅に進化した。ただし連系はまだペーパートレード段階であり、推定オッズと実際のオッズの乖離を実測で確認する必要がある。

最も重要な教訓は、**結果が良すぎるときは必ずバグを疑え**ということ。170%→127%への修正は、外部監査なしには発見できなかった。

## 付録B：競馬AI開発者のための技術メモ

### 特徴量設計で本当に大事なこと

1. **「市場が知らない情報」を入れているか？** — これが全て。170個の特徴量で馬の強さを精密に測っても、市場（他の馬券購入者の合計知見）がすでに同じことを知っていれば、回収率は控除率の壁（約80%）を超えない。「直前のオッズ変動」が効くのは、市場全体がそれを完全に織り込む前の数分間の隙を突いているから

2. **特徴量の数より上位数個が支配する** — 私のモデルでは24個中、1位のmove_5to3が全体の28%を占め、上位4個で54%。残り20個は「あっても少し良い」程度。170個モデルでも、おそらく上位10個で大半のgainを稼いでいるはず

3. **レース内偏差で正規化する** — IDMや騎手指数は「レース平均との差」にすると、未勝利戦とG1を同じ尺度で比較できる。モデルAの真Zスコアも本質的には同じ発想（条件を揃えた上での偏差）

4. **独自指数を作ることの価値** — モデルAの真Zスコアは「予測タイムと実績のズレ」という独自の尺度。JRDBやJRA-VANの既製品を使うのと、自分で作るのでは、後者のほうが市場に織り込まれにくい可能性がある（ただし、独自指数が「公開データの再計算」なら結局同じ）

### 3つのモデル設計から見える教訓

| 教訓 | 内容 |
|------|------|
| 特徴量を増やす＝精度が上がる、ではない | モデルBは推定300個超だが、LightGBMは自分で重要な特徴量を選ぶので、無関係な特徴量はノイズになりうる |
| 距離別にAIを分けるメリット/デメリット | 能力予測なら有効（短距離と長距離で必要な能力が違う）。市場歪み検出なら不要（歪みの構造は距離で変わらない） |
| 地方競馬キャリアの活用 | モデルBの「大井で3勝」などの場別データは面白い。ただし中央のみの予測に地方キャリアがどこまで効くかは検証が必要 |
| 合成オッズは掘り下げる価値がある | 複数券種のオッズ間の不整合は「市場内部の歪み」の可能性。私のモデルの「市場の歪み検出」と方向性が合う |

### AUC 0.7-0.8は良いのか

分類精度としてはまずまず。しかし**AUCと回収率は直結しない**。

- AUC 0.8 で市場が同じことを知っている → 回収率80%（控除率の壁）
- AUC 0.7 で市場が知らない0.01の情報差がある → **回収率100%超えが可能**

AUCを上げる努力が「市場がすでに知っていることの精度改善」なら、回収率には寄与しない。AUCが0.7でも、その0.7の中に「市場が知らない0.01」が含まれていれば、それが回収率を100%の上に押し上げる。

### 次に試す価値がありそうなこと

1. **モデルAの真Zスコア的な発想を取り入れる** — 走破タイムの条件補正偏差を特徴量に追加し、「オッズが示す実力と実際の実力のズレ」をより精密に測る
2. **合成オッズの活用** — 単勝オッズと馬連オッズから逆算した勝率の不整合を検出する特徴量
3. **予測指数の偏差値** — JRDBの予想指数を「レース内の偏差値」として正規化し、市場との乖離を測る
4. **ペース予想の組み込み** — PCI系の指標で「今日のレースが速い展開になるか」を予測し、脚質との相性を評価する

ただし、これらは全て**v8（特徴量探索）で「公開データでは市場に勝てない」と結論づけた**検証を再考することになる。追加する前に「この特徴量は市場がまだ知らない情報を含んでいるか？」を自問する必要がある。
